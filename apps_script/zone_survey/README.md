# 구역편성 기초자료 수집 (Google Apps Script 버전)

구역장님들이 카톡 링크로 접속해 자기 구역 가정의 **기본정보·자녀정보 확인, 최근 2년 출석률(A~D), 동정·특이사항**을 작성하면, 입력한 내용이 **구글시트에 바로 저장**됩니다.

| 파일 | 내용 |
|---|---|
| `Code.gs` | 시트 메뉴, 웹앱 진입점, 저장 API |
| `Parser.gs` | `2025 구역편성(0905)` 시트를 가정 단위로 읽는 파서 |
| `Leader.html` | 구역장 작성 화면 (모바일 최적화) |
| `Messages.html` | 구역별 카톡 메시지 복사 창 |
| `appsscript.json` | 시간대(Asia/Seoul), 웹앱 설정 |
| `deploy.sh` | 시트에 코드 올리기 + 웹앱 배포 (clasp) |
| `Deployment.gs` | 배포 주소 (deploy.sh가 자동 생성) |

## 설치 · 코드 올리기 (자동)

```bash
apps_script/zone_survey/deploy.sh
```

`clasp`로 구글시트에 연결된 스크립트에 코드를 올리고 웹앱으로 배포합니다. 처음 실행하면 스크립트를 만들고 배포 주소를 `Deployment.gs`에 적어 둡니다. 그다음부터는 같은 배포를 새 버전으로 바꾸기만 해서 **구역장 링크 주소가 바뀌지 않습니다.** 코드를 고친 뒤에도 이 명령만 다시 실행하면 됩니다.

- 필요한 것: `clasp login`(crossbow02@gmail.com), [Apps Script API 사용 설정](https://script.google.com/home/usersettings)
- `.clasp.json`(스크립트 ID)과 `.deployment_id`(배포 ID)는 지우지 마세요. 지우면 새 스크립트·새 주소가 만들어집니다.

## 처음 1번만: 시트에서 명단 불러오기

1. 구글시트를 새로고침하면 상단에 **[구역편성 설문]** 메뉴가 생깁니다.
2. **[1. 명단 불러오기]** 를 누르고 권한을 승인합니다. "확인되지 않은 앱"이라고 나오면 **고급 → (안전하지 않음)으로 이동**을 눌러주세요. 내가 만든 스크립트라서 나오는 경고입니다. 승인 전에는 웹앱 링크도 "권한 필요"로 열리지 않습니다.
3. 승인 후 메뉴 1번을 한 번 더 누르면 `구역편성_가정`, `구역편성_링크` 시트가 생기고, **구역별 링크와 카톡 메시지까지 자동으로** 채워집니다.
4. 메뉴 **[카톡 메시지 복사하기]** 를 누르면 구역별 메시지 창이 뜹니다. 구역마다 **[복사]** 를 누르고 카톡에 붙여넣으면 메시지 전문과 그 구역 링크가 함께 들어갑니다.
   - 시트의 **카톡 메시지** 칸에도 같은 내용이 있지만, 칸을 통째로 복사하면 줄바꿈 때문에 앞뒤에 `"`가 붙습니다. 그래서 복사 창을 쓰는 것을 권합니다.
   - 메시지 문구는 `Code.gs` 위쪽 `KAKAO_MESSAGE`에서 바꿀 수 있습니다. 바꾼 뒤 `deploy.sh`를 실행하고 메뉴 2번을 누르면 다시 만들어집니다. 링크는 바뀌지 않습니다.

## 25·26년 출석 기록 (출석률 참고)

메뉴 **[출석 기록 불러오기 (25·26년)]** 를 누르면 `구역편성_가정` 시트의 **25년 출석률 · 26년 출석률** 칸이 채워지고, 구역장 화면의 '최근 2년 출석률' 아래 참고로 나옵니다 (`Attendance.gs`).

- 25년: 2025 출석부 스프레드시트의 `25 상반기 개인별 출석률` 시트 → 출석횟수 / 총구역모임 수
- 26년: 출석부 시스템 스프레드시트의 날짜 시트(`0315`, `1018` …) → 자기 구역이 모임한 주(모임없음·미제출·휴무 제외) 중 출석한 주
- 이름은 같은 구역 출석부에서 찾고, `김수연`/`김수연B`처럼 구분 글자만 다르면 같은 사람으로 봅니다. 26년 출석부에 이름이 한 번도 없으면 0%로 나옵니다.
- 새 출석부가 쌓이면 메뉴를 다시 누르면 갱신됩니다. 명단 불러오기(메뉴 1번) 때도 자동으로 채웁니다.

## 진행 중 확인

- `구역편성_링크` 시트: 구역별 **가정 수 / 작성 완료 / 최종 제출** 시각이 실시간으로 보입니다.
- `구역편성_가정` 시트: 구역장이 저장할 때마다 해당 행이 바로 바뀝니다. **수정된 항목** 칸에 명단과 달라진 정보(예: `형제 연락처, 자녀`)가 표시됩니다.
- '작성 완료'는 **정보 확인 체크 + 출석률 선택**이 모두 된 가정입니다.
- **내년 구역장 추천**: 구역장이 가정마다 체크할 수 있고(여러 가정 가능), `구역편성_링크` 시트의 **구역장 추천 가정** 칸에 구역별로 모여 보입니다.
- **3마을 이동**: 원본 시트에서 자녀 칸이 **노란색(#FFFF00)**인 가정이 대상입니다(`3마을 대상(노란색)` 열에 `Y`). 처음에는 모두 체크된 상태이고, 구역장이 아니라고 하면 해제합니다. 대상이 아닌 가정에는 이 체크가 나오지 않습니다. 구역장 줄의 연한 노랑은 대상이 아닙니다.
  - 불러온 뒤 대상을 직접 바꾸려면 `3마을 대상(노란색)` 칸에 `Y`를 넣거나 지우고, `3마을 이동` 칸도 `✓`로 맞춰주세요.

## 마무리: 1마을 형식으로 정리

**[3. 결과 시트 만들기]** 를 누르면 `1마을 올라오는 가정 정리`와 같은 형식(NO · 현재 구역 · 이름 · 생년월일 · 자녀 · 출석률 · 동정, 가정당 2줄 병합)으로 `구역편성_결과` 시트를 만듭니다. 내년 배정 의견, 구역장 추천, 3마을 이동, 정보 수정, 구분 칸도 함께 들어갑니다. 여러 번 눌러도 매번 새로 만듭니다.

## 주의

- 구역장님들이 작성을 시작한 뒤에는 **1. 명단 불러오기를 다시 누르지 마세요.** 작성 내용과 링크가 모두 새로 만들어집니다. (누르면 경고창이 한 번 더 뜹니다.)
- `구역편성_가정`의 **ID**, `구역`, `원본` 열과 `구역편성_링크`의 **토큰** 열은 고치지 마세요. 다른 칸(예: 오타 수정)은 시트에서 직접 고쳐도 됩니다.
- 코드를 고친 뒤에는 `deploy.sh`를 다시 실행하면 됩니다. 링크 주소는 그대로입니다.
- 링크를 아는 사람은 누구나 그 구역 화면을 열 수 있습니다. 링크는 해당 구역장님께만 보내주세요. 토큰을 바꾸고 싶으면 `토큰` 칸을 새 값으로 바꾸고 메뉴 2번을 다시 누르면 됩니다.
- 내년에 다시 쓸 때는 `Code.gs` 맨 위 `SOURCE_SHEET`를 새 편성 시트 이름으로 바꾸면 됩니다.
